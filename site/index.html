Your Unraid server, in your pocket.

NOVA is a community-built, open-source Android client for Unraid® servers: array health, container and VM state and live system metrics in a clean Material 3 interface tuned for quick mobile checks.

What it does

  • Overview

    Array capacity, live CPU and memory, container and VM counts and parity-check progress at a glance.

  • Array

    Per-disk status, temperatures and capacity. Start and stop the array.

  • Docker

    Every container with its status. Start, stop, restart or pause one, jump to its Web UI, see live container logs, and find out which containers have an image update and apply it, for one container or all.

  • VMs

    The state of every virtual machine, with start, stop, pause and resume.

  • Multiple servers

    Switch between servers. Each one has its own local and remote address.

  • Notifications

    Unraid notifications with Unread and Archived tabs.

  • Plugins and network

    A read-only inventory of server plugins with their install history, and a read-only list of network interfaces (IPv4, IPv6 and hardware).

  • Your look

    In Settings, pick an accent colour (mint, blue, purple, amber or red), dark or light mode, a padding density and a Docker layout (list, grid or grouped by state).

Install

NOVA comes in two builds of the same app, one for F-Droid and one from GitHub. They differ only in how they are updated.

F-Droid

The F-Droid build follows the stable releases. F-Droid installs and updates it; the app has no updater of its own and makes no GitHub requests for updates.

NOVA on F-Droid

GitHub

Download the APK from the latest release. This build has an in-app updater that checks GitHub, and an optional “Include pre-releases” setting if you want betas. Android asks you to allow installs from your browser or files app, which is expected for apps from outside a store.

Latest release · All releases

The two builds cannot update each other. They are signed with different keys, so Android refuses to install one over the other. To switch, uninstall one and install the other. Uninstalling removes the app’s local data, so you add your servers again.

Requirements

  • Android 8.0 or newer.
  • An Unraid 7.x server with the API/Connect plugin enabled.
  • All app features need Unraid API 4.30.0 or newer; the live network speed needs 4.35.0 or newer (API versions, not Unraid OS versions). On an older API some screens fail to load.

Set it up

  1. On your Unraid server, create an API key: web UI, Settings → Management Access → API / Connect.
  2. Open the app and choose Add server. Fill in a Server name (a label), the Local host (its address on your home network, for example 192.168.1.10; switch on Use SSL (HTTPS) if the server uses HTTPS), optionally a Remote host (Unraid Connect) for when you are away, and the API Key you just created.
  3. Tap Test, then Save. The pill in the top bar switches between Local and Remote.

Verify the GitHub APK

The APKs on GitHub are signed with one release key. Its certificate SHA-256 is public, so you can compare it with the output of apksigner verify --print-certs on a downloaded APK:

Privacy

The short version of the privacy policy, which is the authoritative text.

  • Stays on your device

    Your API key is stored encrypted with the Android Keystore and is excluded from cloud backup and device transfer. It only leaves the device in requests to your own Unraid server.

  • Your server

    All app functionality runs through your own server, at the addresses you configured.

  • Container icons

    The icon of each container comes from a URL your server provides, usually a host chosen by the template author, such as raw.githubusercontent.com, cdn.jsdelivr.net or github.com. The app fetches it directly, so that host sees your IP address. NOVA adds no credentials to these requests.

  • Update check (GitHub build)

    The GitHub build contacts api.github.com when the app starts, when you open Settings and when you press “Check now”. An in-app update is downloaded from a GitHub release. The F-Droid build makes no such requests.

  • Nothing else

    No analytics, no telemetry, no crash reporting, no advertising and no third-party sign-in. Uninstalling the app removes everything it stored.
