# Google Play App content declarations for NOVA

Play Console, Policy and programs, App content. Sources: <https://support.google.com/googleplay/android-developer/answer/9859455> and <https://support.google.com/googleplay/android-developer/answer/10788890> (read 2026-11-13). The maintainer enters these; the answers are what the code and the project's decisions support.

| Declaration                                  | Answer                                                                 | Basis                                                                                                                                                  |
| -------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Privacy policy                               | <https://github.com/hellwand/nova/blob/main/docs/privacy/POLICY.md>    | Google: "You must link to a privacy policy on your store listing and within your app". Already linked in the app (`SettingsScreen.kt:413`). See `data-safety.md` for the page-format caveat. |
| Ads                                          | **No**, the app contains no ads                                         | No advertising SDK (`app/build.gradle.kts:148-188`; `docs/privacy/POLICY.md:29`).                                                                      |
| App access                                   | Restricted: instructions in [`app-access.md`](./app-access.md)          | The app is unusable without an Unraid server; reviewers need a way in.                                                                                 |
| Content rating                               | [`content-rating.md`](./content-rating.md)                              |                                                                                                                                                        |
| Target audience and content                  | **18 and over** only                                                    | A server-administration tool; it does not appeal to children. Choosing only the adult group keeps the Families policy, which "applies to apps that include children", out of scope. |
| Data safety                                  | [`data-safety.md`](./data-safety.md)                                    |                                                                                                                                                        |
| Advertising ID                               | **No**, the app does not use it                                         | No advertising SDK and no `com.google.android.gms.permission.AD_ID` in the manifest (`AndroidManifest.xml:5-15`).                                      |
| Government apps                              | No                                                                      | Independent hobby project.                                                                                                                             |
| Financial features                           | None                                                                    | No payments, banking or loans.                                                                                                                         |
| Health apps                                  | None                                                                    | No health features.                                                                                                                                    |
| News app                                     | No                                                                      |                                                                                                                                                        |
| Permissions declaration forms                | None needed (not looked up on Google's side)                            | Only `INTERNET` and `ACCESS_NETWORK_STATE`, both normal permissions (`AndroidManifest.xml:5-6`). Google's list of forms for high-risk permissions was not read. |
| Package name                                 | `io.github.nofuturekid.nova`                                            | Must be registered when the app is created in Play Console (Play Console Requirements 3.4); it cannot be renamed later.                                |
| Target API                                   | 36                                                                      | `app/build.gradle.kts:18`; Google requires 36 or higher for new apps and updates from 2026-08-31 (<https://support.google.com/googleplay/android-developer/answer/11926878>). |
| Trader status (EU)                           | The maintainer's own legal declaration; the plan recommends non-trader  | See the plan in issue #328. Not decided in this repository.                                                                                            |
