# Google Play content rating: questionnaire answers for NOVA

Play Console, App content, Content rating (IARC questionnaire; "Unrated apps may be removed", <https://support.google.com/googleplay/android-developer/answer/9859455>). Answers below follow what the `store` flavor does; the maintainer enters them. The expected result is the lowest rating in every system; that is an expectation, not something Google has confirmed.

| Question group                                                      | Answer                                                              | Basis                                                                                                              |
| ------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Category                                                            | Utility, productivity, communication or other (not a game)           | A remote-administration client for a user's own NAS server.                                                         |
| Violence, blood, fear                                               | No                                                                  | The app shows server status, disks, containers and VMs only.                                                        |
| Sexual content, nudity                                              | No                                                                  | Same.                                                                                                              |
| Profanity or crude humour                                           | No                                                                  | Same.                                                                                                              |
| Controlled substances (drugs, alcohol, tobacco)                     | No                                                                  | Same.                                                                                                              |
| Gambling or simulated gambling                                      | No                                                                  | Same.                                                                                                              |
| User-generated content or user-to-user interaction                  | No                                                                  | The app has no accounts and no way for users to share or communicate. Container names, logs and Unraid notifications come from the user's own server and are shown only to that user. |
| Shares the user's location with other users                         | No                                                                  | No location permission (`AndroidManifest.xml:5-6`).                                                                 |
| Digital purchases or in-app purchases                               | No                                                                  | No billing library.                                                                                                |
| Unrestricted web access or a web browser                            | No                                                                  | NOVA does not render web pages. Links ("Open Web UI", GitHub) are handed to the user's own browser (`ContainerDetailSheet.kt:286-288`, `SettingsScreen.kt:393-413`). |
| Collects or shares personal data (as asked in the questionnaire)    | No (see `data-safety.md`)                                           | Same judgement as in the Data safety form; keep the two consistent.                                                 |
| Ads                                                                 | No                                                                  | `app-content.md`.                                                                                                  |

Expected outcome: PEGI 3, ESRB Everyone, USK 0, IARC 3+ (not yet confirmed by the questionnaire).
